# 実機チェックリスト

単体テストで確かめられないことを、iPhone で確かめる手順（D-71）。機能を足す PR は、その機能の確認項目をここに足す。

## インストール

無料の開発者アカウントの署名は7日で切れる（D-01）。切れたら同じ手順で入れ直す。

1. iPhone を Mac につなぎ、ロックを解除する。
2. Linux で `scripts/mac install` を実行する。ログインキーチェーンにロックがかかっていれば、Mac のログインパスワードを聞かれる。
3. 初回だけ、iPhone の「設定 > 一般 > VPN とデバイス管理」で開発元を信頼する。
4. 初回だけ、「設定 > 一般 > キーボード > キーボード > 新しいキーボードを追加」で「Practical」を追加し、「フルアクセスを許可」をオンにする（D-04）。

## 確認すること

- [ ] アプリが起動し、「Practical」と表示される。
- [ ] 任意のアプリの文字入力で地球儀キーから Practical に切り替えると、「Practical」と表示されたキーボードが出る。
